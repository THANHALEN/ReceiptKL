HƯỚNG DẪN UPLOAD TỪ ĐIỆN THOẠI

1. Giải nén ZIP này.
2. Trên GitHub, bấm “uploading an existing file”.
3. Chọn đồng thời 6 file ở cùng thư mục: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png.
4. Commit changes.
5. Settings → Pages → Deploy from a branch → main / (root) → Save.
6. Mở link GitHub Pages bằng Chrome Android, sau đó chọn “Cài đặt ứng dụng”.
